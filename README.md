# Termux-boost-ram-no-root-
What You Need to Prepare: The Termux app and the Shizuku app. A script that you can download from the link below. ⬇️ Watch the tutorial on YouTube before using it to avoid any errors. 🛑

Note: This script does not directly boost performance. It is suitable for users who want to clear cache quickly and reduce the activity of unnecessary apps, or stop them from running entirely, to save battery and indirectly reduce CPU workload.

For gamers, this script may help improve the gaming experience by clearing cache, freeing up system resources, and potentially improving data read/write performance. Closing apps or using RAM-clearing commands may also free up memory for games, helping reduce unexpected game crashes and improve stability. 🔥

```termux-setup-storage```

```sh /sdcard/Ko/rish -c "cat /sdcard/Ko/rish" > ~/rish```

```sh /sdcard/Ko/rish -c "cat /sdcard/Ko/rish_shizuku.dex" > ~/rish_shizuku.dex```

```chmod +x ~/rish ~/rish_shizuku.dex```

```sh /sdcard/Ko/rish -c "cat /sdcard/Ko/turbo.sh" > ~/turbo.sh```

```chmod +x ~/turbo.sh```

```bash turbo.sh```
