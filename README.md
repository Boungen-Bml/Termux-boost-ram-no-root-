# Termux-boost-ram-no-root-
What You Need to Prepare: The Termux app and the Shizuku app. A script that you can download from the link below. ⬇️ Watch the tutorial on YouTube before using it to avoid any errors. 🛑


pkg install aapt -y

sh /sdcard/Download/rish -c "cat /sdcard/Download/rish" > ~/rish

sh /sdcard/Download/rish -c "cat /sdcard/Download/rish_shizuku.dex" > ~/rish_shizuku.dex

chmod +x ~/rish ~/rish_shizuku.dex

~/rish -c "echo OK”

ls ~/turbo.sh

sh /sdcard/Download/rish -c "cat /sdcard/Download/turbo.sh" > ~/turbo.sh
chmod +x ~/turbo.sh

cd ~
bash turbo.sh

ls ~/rish ~/rish_shizuku.dex
~/rish -c "echo OK"
ls ~/turbo.sh

cd ~
bash turbo.sh
